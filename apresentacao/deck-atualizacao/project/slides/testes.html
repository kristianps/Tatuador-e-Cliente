08 · Testes automáticos

Cada regra importante tem um teste

ArquivoO que ele confere
test_autenticacao.pyLogin, JWT que expira, hash das senhas e bloqueio após 5 erros
test_permissoes.pyA cliente só vê e mexe nos próprios pedidos
test_servico_passo.pyA ordem das etapas, com o retoque só depois da finalização
test_ia_resumo.pyO resumo do pedido feito pela IA
test_ia_reserva.pyA troca de modelo quando um falha
test_pedido_imagens.pyA validação das imagens enviadas no pedido

O GitHub Actions roda todos os testes sozinho a cada envio de código.

Os testes ficam em backend/tests e rodam no GitHub a cada push, então uma mudança que quebre uma regra aparece na hora.
