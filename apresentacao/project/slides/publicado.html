Antes de abrir o sistema, mostre o caminho de uma requisição. A tela e a API são dois projetos separados na Vercel. A tela chama /api, e o rewrite do vercel.json leva até a API. A API fala com o PostgreSQL do Supabase por uma conexão com SSL, usando a variável URL_DO_BANCO. A senha do banco nunca fica no front.
