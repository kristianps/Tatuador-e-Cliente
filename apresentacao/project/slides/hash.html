A API aplica PBKDF2-SHA256 com 100 mil iterações antes de gravar.

Todo cadastro público nasce como cliente.

No Supabase, abra a linha do usuário recém-criado e aponte a coluna senha_hash: o valor não tem nenhuma relação visível com a senha digitada. No login, a API calcula o hash da senha informada e compara com o valor guardado. O perfil é definido pelo backend, e não pelo que chega na requisição.
