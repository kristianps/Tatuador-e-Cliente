Faça o teste ao vivo com a senha errada. A mensagem não diz se o erro está no e-mail ou na senha, para não revelar quais contas existem. A API responde com status 401 e a tela mostra o texto. No cadastro, é possível testar também senhas diferentes ou um e-mail que já existe.
